# Smart Greenhouse — Phase Roadmap

This project follows the Design Patterns course phases in numerical order.

## Required phases

| Phase | Focus |
|---|---|
| 1 | Skeleton |
| 2 | Factory Method |
| 3 | Abstract Factory |
| 4 | Builder |
| 5 | Adapter |
| 6 | Strategy |
| 7 | Facade |
| 8 | State |
| 9 | Decorator |
| 10 | Command |
| 11 | Observer |
| 12 | Production API, WebSocket, and schema hardening |

## Optional enrichment

| Phase | Focus |
|---|---|
| 13 | Dashboard polish |
| 14 | Tests, documentation, and demo |

## Current status

### Phase 1 — Skeleton

**Status: Complete**

Phase 1 establishes the three-tier project foundation:

- FastAPI backend
- PostgreSQL database
- Alembic migration tooling
- React + TypeScript frontend
- Tailwind CSS v4
- React Router
- Health API
- Frontend health badge
- Smart Greenhouse dashboard placeholders

No design pattern is implemented in Phase 1.

## Phase order

The phases should be completed in numerical order. Each later phase builds on the structure established by the previous phases.
